# PitCloneDB

This is my CDN database for my AI Studio projects. Some assets are custom, some are licensed assets. Please don't yank these files, at least without asking first.

## Resource Directory

### 3D Assets
| Path | Category |
|------|----------|
| `3D/character` | Character Models |
| `3D/entities` | Entity Models |
| `3D/environment` | Environment Assets |
| `3D/items` | Item Models |
| `3D/levels` | Level Models |
| `3D/objects` | Object Models |

### Audio Assets
| Path | Category |
|------|----------|
| `audio/DungeonCrawler` | DungeonCrawler Audio |
| `audio/interface` | Interface Sounds |
| `audio/music` | Background Music |
| `audio/sfx` | Sound Effects |

### Image Assets
| Path | Category |
|------|----------|
| `image/IsodunIcons` | Isodun Icon Assets |
| `image/IsodunTutorials` | Isodun Tutorial Graphics |
| `image/leveltextures` | Level Textures |
| `image/uiTextures` | UI Textures |
